#  Running the Test Script  

To execute the test file, run the following command in your terminal:  
```sh
ts-node test/launcher.ts
```

### **Requirements:**
- **Node.js** installed (`node -v` to check).
- **TypeScript and ts-node** installed globally or within the project:
  ```sh
  npm install -g ts-node typescript
  ```
  Or, if using a local installation:
  ```sh
  npm install --save-dev ts-node typescript
  ```


## **Available Test Commands**
The script allows testing different API methods by passing arguments in the terminal.

### **1. Test a `GET` request**
Retrieve all spaces:
```sh
ts-node test/launcher.ts GET
```

### **2. Test a `GET` request with an ID**
Retrieve a specific space by ID:
```sh
ts-node test/launcher.ts GET_BY_ID 527495f1-15bb-4025-9ce9-516d2cfc45db
```
(Replace the ID with an actual one from your database.)

### **3. Test a `POST` request**
Create a new space by specifying a location:
```sh
ts-node test/launcher.ts POST "New York"
```

### **4. Test a `PUT` request**
Update a space by specifying a location:
```sh
ts-node test/launcher.ts PUT 527495f1-15bb-4025-9ce9-516d2cfc45db "Paris Update"
```

### **Using a `.env` file (Recommended for Local Testing)**
Instead of passing environment variables every time, create a `.env` file in the root directory:
```
AWS_REGION=region
TABLE_NAME=SpacesTable
```
